# Briefing del servicio · OBR

App de repaso para el alumnado de 1º CFGM Servicios en Restauración (CIPFP Dénia) antes de cada servicio real.

- Abrir la app: la dirección de esta web.
- Abrir con la estación ya elegida: añadir `?est=MA`, `?est=SU`, `?est=BA`, `?est=CA`, `?est=CF` o `?est=TR` al final de la dirección.

No guarda datos del alumnado en ningún servidor: todo queda en el móvil y la nota viaja en el código de resultado.
